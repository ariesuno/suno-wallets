# Collections Legadas do Postman

Este diretório contém as collections antigas do Postman que foram consolidadas na nova collection unificada.

## ⚠️ Arquivos Legados

Estes arquivos foram mantidos apenas para referência histórica:

- `postman_collection.json` - Collection principal antiga
- `postman_b3_admin.json` - Endpoints administrativos B3
- `postman_b3_complete_sync.json` - Sincronização completa
- `postman_b3_data.json` - Dados e preview B3
- `postman_backoffice_admin.json` - Administração backoffice
- `postman_client_policy.json` - Políticas de cliente
- `postman_manual_ops.json` - Operações manuais
- `postman_reconciliation.json` - Reconciliação
- `postman_timeline_summary.json` - Timeline e sumários

## 📋 Migração

Todos estes endpoints foram migrados para a nova collection unificada:
`/docs/collections/postman/Suno_Wallets_Complete_Collection.json`

## 🚀 Recomendação

**Use a nova collection unificada** que oferece:
- Melhor organização
- Cobertura completa de endpoints
- Documentação aprimorada
- Testes automatizados
- Ambientes padronizados

Para mais informações, consulte: `/docs/collections/README_Postman_Collections.md`
