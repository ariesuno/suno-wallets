
# Prompt de Validação - 1.4 Infrastructure Layer (suno-wallets)

Você deve validar se a entrega do **1.4 Infrastructure Layer** do projeto `suno-wallets` está completa, consistente e seguindo todos os padrões definidos anteriormente.

## Itens obrigatórios para validação

1. **Padrão de Nomenclatura**
   - Todos os nomes de arquivos, pastas, funções, classes e variáveis devem estar em **inglês**.
   - Comentários devem estar em **português do Brasil**.
   - Estrutura de pastas respeitando o DDD (Domain-Driven Design).

2. **Estrutura de Pastas**
   - `Infrastructure/Repositories`
   - `Infrastructure/Data`
   - `Infrastructure/ExternalApis`
   - `Infrastructure/BackgroundJobs`
   - Testes unitários na pasta `Tests/Infrastructure`.

3. **Banco de Dados**
   - Configuração correta do PostgreSQL.
   - Scripts de migração para criação das tabelas base.
   - Conexão via variáveis de ambiente seguras.
   - Configuração para execução via Docker.

4. **Cache e Filas**
   - Configuração do Redis.
   - Implementação de conexão e testes básicos.
   - Configuração para filas (ex: para consolidação assíncrona).

5. **Observabilidade**
   - Integração inicial com Grafana/Prometheus/Loki ou OpenTelemetry.
   - Configuração mínima de métricas e logs no nível de infraestrutura.

6. **Testes**
   - Testes unitários para os repositórios.
   - Testes de integração para conexão com banco de dados e Redis.

7. **Documentação**
   - Atualização do `README.md` com instruções de setup da infraestrutura.
   - Inclusão de comandos para rodar localmente com Docker.

8. **Boas Práticas**
   - Uso de `.env` para credenciais e configurações sensíveis.
   - Scripts de inicialização claros.
   - Separação entre código de aplicação e infraestrutura.

## Ação
Se todos os pontos acima estiverem atendidos, aprove a entrega. Caso contrário, liste os ajustes necessários antes da aprovação.
