# Prompt de Validação - Entrega 1.2 (User Module)

Você deve analisar **todo o código gerado** para a entrega da etapa 1.2 do Bloco 1 e validar se **atende a 100%** dos requisitos definidos no prompt estruturante 1.2.

## Itens obrigatórios para validação

1. **Arquitetura e Estrutura**
   - Segue o padrão **DDD** (Domain-Driven Design).
   - Estrutura de pastas coerente com o restante do projeto.
   - Nomes de arquivos, funções e classes **em inglês**.
   - Comentários de código **em português-br**.
   - Testes criados na pasta correta, seguindo a convenção definida.

2. **Implementação**
   - Implementa corretamente todas as entidades, agregados, value objects, serviços e interfaces especificadas no prompt original.
   - Não há código morto ou não utilizado.
   - Boas práticas de clean code, SOLID e separação de responsabilidades.
   - Tipagem forte (quando aplicável).

3. **Testes**
   - Cobertura mínima de testes conforme diretriz do projeto.
   - Testes escritos de forma clara, validando casos positivos e negativos.
   - Organização correta dentro da pasta de testes.

4. **Consistência**
   - Alinhamento com as convenções definidas no arquivo de diretrizes do projeto.
   - Coerência com os outros módulos já desenvolvidos.
   - Nomes consistentes e padronizados em todo o módulo.

## Resultado esperado

Ao final, apresente um **relatório detalhado** com:
- Lista de conformidades encontradas.
- Lista de não conformidades (com indicação de como corrigir).
- Avaliação geral de integridade (APROVADO / REPROVADO).
