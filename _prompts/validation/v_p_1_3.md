
# Prompt de Validação - 1.3 Domain Layer

Você deve validar se a entrega do módulo **Domain Layer** foi feita conforme as diretrizes estabelecidas.  
Analise cuidadosamente o código gerado e verifique os seguintes pontos:

- A camada `Domain` foi criada dentro de `src/Domain`.
- Contém as pastas **Entities**, **ValueObjects**, **Enums** e **Interfaces**.
- Cada pasta possui ao menos um arquivo de exemplo relacionado ao módulo inicial do projeto.

- **Interfaces** estão tipadas corretamente e representam contratos claros.
- O código está comentado **em português do Brasil**, explicando a função de classes e métodos.

- O código está limpo e organizado, seguindo boas práticas de programação.

- Os nomes dos testes seguem padrão descritivo, em inglês.
