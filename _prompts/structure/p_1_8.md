# Prompt 1.8 – B3 Positions Fetch

Implemente o módulo para **buscar as posições do cliente na API da B3** no projeto **suno-wallets**.

## Objetivo
Consumir os 5 endpoints de posições da API da B3, com controle de período, tratamento de erros e rate limit.

## Regras e Diretrizes
1. **Arquitetura**
   - Implementar em `Application/B3` e `Infrastructure/B3` seguindo DDD.
   - Métodos para buscar posições por tipo de ativo e período.

2. **Funcionalidades**
   - Função para buscar todas as posições desde o início do histórico.
   - Endpoint **/b3/fetch/positions/preview** para teste (não persiste).
   - Retry e backoff para lidar com erros temporários.

3. **Observabilidade**
   - Logs detalhados por chamada.
   - Métricas de volume, latência e falhas.

4. **Testes**
   - Unitários para parsing e formatação de resposta.
   - Integração para conexão real com a B3.

5. **Entrega Final**
   - Código funcional, testado e documentado.
