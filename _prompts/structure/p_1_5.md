
# Prompt 1.5 – Configuração de Observabilidade

Você é responsável por implementar a camada de observabilidade do projeto **suno-wallets**, garantindo monitoramento, métricas, logs e rastreabilidade completos desde o início.

## Objetivo
Configurar a stack de observabilidade com Grafana, Prometheus e Loki (ou OpenTelemetry), assegurando que todos os serviços, jobs e APIs sejam monitorados e rastreados adequadamente.

## Regras e Diretrizes
1. **Arquitetura**:
   - Usar Grafana para dashboards de métricas e visualização.
   - Usar Prometheus para coleta de métricas.
   - Usar Loki (ou OpenTelemetry) para centralização de logs.
   - Configurar alertas de falha e degradação de performance.

2. **Cobertura de Monitoramento**:
   - Todos os endpoints da API devem ter métricas de latência, requisições por segundo e taxa de erro.
   - Jobs de consolidação, ingestão de dados e processamento assíncrono devem ter métricas de sucesso, falha e tempo de execução.
   - Logs devem conter o `TenantID` para rastreabilidade em ambiente multi-tenant.

3. **Padrões de Código**:
   - Nomes de arquivos, funções, variáveis e classes em **inglês**.
   - Comentários em **português-brasileiro** explicando a função e uso de cada parte do código.
   - Código organizado no padrão **DDD** (Domain-Driven Design), integrando monitoramento diretamente na camada de infraestrutura.

4. **Pasta de Testes**:
   - Criar testes automatizados para validar se as métricas e logs estão sendo registrados corretamente.
   - Salvar todos os testes na pasta `tests/integration` ou `tests/unit` conforme o caso.

5. **Documentação**:
   - Incluir instruções de execução e configuração da stack de observabilidade no `README.md`.
   - Criar exemplo de dashboard básico no Grafana para visualização de métricas principais.

6. **Entrega Final**:
   - Código completo e funcional.
   - Configuração Docker para subir a stack de observabilidade.
   - Documentação clara no `README.md`.
