# Prompt 1.6 – B3 Client & Auth

Você é responsável por implementar o **cliente de conexão com a API da B3** para o projeto **suno-wallets**, garantindo autenticação segura, logging e resiliência.

## Objetivo
Criar o módulo responsável por autenticar e se conectar à API da B3, incluindo suporte a certificados, credenciais e controle de erros.

## Regras e Diretrizes
1. **Arquitetura**
   - Implementar dentro da camada `Infrastructure/B3` seguindo o padrão **DDD**.
   - Configurações sensíveis via variáveis de ambiente (.env) — **nunca hardcode**.
   - Requisições usando `HttpClient` ou biblioteca equivalente com suporte a timeout e retry.

2. **Funcionalidades**
   - Método para autenticar e retornar token válido.
   - Validação automática de expiração de token e refresh quando necessário.
   - Incluir identificador de tenant em todas as requisições para logging.

3. **Observabilidade**
   - Logs detalhados em cada tentativa de autenticação e requisição.
   - Métricas: tempo de resposta, taxa de sucesso e erros por endpoint.

4. **Pasta de Testes**
   - Testes unitários em `/src/Tests/Unit/B3` para validar autenticação e resposta da API.
   - Testes de integração para verificar conexão real com a B3 (usar CPF de teste válido).

5. **Entrega Final**
   - Código funcional e testado.
   - Documentação no README explicando configuração e uso.
