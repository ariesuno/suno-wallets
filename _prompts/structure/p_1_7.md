# Prompt 1.7 – B3 Transactions Fetch

Implemente o módulo para **buscar as transações do cliente na API da B3** no projeto **suno-wallets**.

## Objetivo
Criar serviço para consumir os 5 endpoints de transações da API da B3, com suporte a busca por períodos (mês a mês), tratamento de erros e controle de rate limit.

## Regras e Diretrizes
1. **Arquitetura**
   - Implementar em `Application/B3` e `Infrastructure/B3` seguindo DDD.
   - Métodos para buscar transações por tipo de ativo e período.

2. **Funcionalidades**
   - Função para buscar todas as transações desde o início do histórico disponível na API.
   - Endpoint **/b3/fetch/transactions/preview** para teste (não persiste no banco).
   - Retry e backoff para lidar com erros temporários.

3. **Observabilidade**
   - Logs detalhados por chamada à B3.
   - Métricas de volume, latência e falhas.

4. **Testes**
   - Unitários para parsing e formatação de resposta.
   - Integração para conexão real com a B3.

5. **Entrega Final**
   - Código funcional, testado e documentado.
